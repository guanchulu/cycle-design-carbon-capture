# Data and code for: Cycle design reshapes the economics of nitrogen recovery in adsorption-based carbon capture

Data and code release for the study "Cycle design reshapes the economics of nitrogen recovery in adsorption-based carbon capture" (under review).

## Contents (release v1.0.0 assets)

- `Performance_Analysis.zip` — the four principal archived input sets, trajectory extraction, integrated-phase tables, performance-to-cost checks and the data used in the performance figures
- `Data_and_Code_Optimization.zip` — the optimized numerical release
- `Previous_Upgrade_Data_and_Code.zip` — the preceding numerical release
- `Baseline_Data_and_Code.zip` — the baseline numerical release
- `Review_Revision_Data_and_Code.zip` — the geometry, capacity and financial stress tests
- `Figure5_6_DataAndCode.zip` — editable SVG and 600 dpi PNG figures 5-6, plotting scripts and frozen input data

SHA-256 checksums for every asset are listed in `SHA256SUMS.txt`.
